# KV Social Implementation Plan

> Execution: inline with executing-plans; isolated GitHub branch and draft PR authorized by the selected task.

**Goal:** Reviewable mobile feed and owner moderation pilot without touching ticket transactions.
**Architecture:** Independent Express service, memory-only synthetic records, fixed demo identities from private keys, plain JS frontend.
**Tech Stack:** Existing Node/Express, node:test, Playwright.
**Spec:** ../specs/2026-10-11-kv-social-design.md

## Global constraints
No production data, email, payment or deployment. All community submissions pending. KV Social naming. No invented crown. Public release stays blocked.

## Review focus
Session expiry/revocation; forged identity fields; duplicate/replayed review actions; hidden comments under removed parents; simultaneous requests and unbounded memory. Include behavioral checks in API tests.
